Shopify & WooCommerce Product + Price Tracker

Pull title, price, SKU, stock and URL from Shopify and WooCommerce stores to CSV/JSON.

Open on Apify Store

How to run

  1. Open ecommerce-product-data-half-price on Apify (free Apify account works for a trial run).
  2. Click Try for free / create a run.
  3. Keep or edit the sample input below, then Start.
  4. Download the dataset as JSON or CSV when the run succeeds.

Sample input

{
  "startUrls": [
    {
      "url": "https://scrapeme.live/shop/"
    },
    {
      "url": "https://nomadgoods.com"
    }
  ]
}
