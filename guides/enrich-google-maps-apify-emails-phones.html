How to enrich a Google Maps Apify dataset with emails and phones

Last updated 13 Oct 2026 · Worldwide · Apify

Short answer. A Google Maps scrape gives you names, addresses and website URLs. It does not give you emails. To add role emails, phones and WhatsApp links, run any Google Maps Actor first, copy its dataset ID, then run a contact-details Actor that visits each company's public website. Sites that block crawling via robots.txt or terms are skipped and reported.

What you need

  • An Apify account (free trial is enough to try)
  • A finished Google Maps Actor run that includes a website field
  • The dataset ID from that run (Apify console → run → Dataset → ID)

Step 1 — Finish your Maps scrape

Use any Google Maps Actor you already trust. Export is not required; you only need the dataset ID. Branches or listings that share one website will be crawled once in the next step.

Step 2 — Pass the dataset ID to a contact-details Actor

Open Contact Details Scraper: Emails, Phones (Half Price) on the Apify Store and use this input:

{
  "datasetId": "",
  "maxPagesPerSite": 4,
  "defaultCountry": "IN",
  "checkEmailMx": true
}

Or from Python (pip install apify-client):

from apify_client import ApifyClient
client = ApifyClient("")
run = client.actor("laudable_instrument/contact-details-scraper-half-price").call(
    run_input={"datasetId": "", "maxPagesPerSite": 4, "defaultCountry": "IN", "checkEmailMx": True}
)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("domain"), item.get("counts"), item.get("status"))

What you get back

One row per website (not per Maps listing): role emails with MX check, E.164 phones, WhatsApp/Telegram links, social profiles, and the page each was found on. Status values include ok, blocked-by-robots, blocked-by-terms, rate-limited and failed.

Privacy default

Only shared role mailboxes (info@, sales@, support@) are returned by default. Addresses that identify one person are dropped unless you turn includePersonalEmails on with a lawful basis under India's DPDP Act or the EU/UK GDPR. This is general information, not legal advice.

Responsible use. The Actor reads only public pages, uses an honest bot User-Agent, follows robots.txt, never logs in and never gets around blocks. You are responsible for how you use the data.

FAQ

Can I get emails from a Google Maps Apify scrape?

Not from the Maps listing itself. Pass the dataset ID to a contact-details Actor that visits each company website where crawling is allowed.

Does this scrape personal emails?

By default no. Only role mailboxes unless you explicitly enable personal emails with a lawful basis.
