“7000 ka penalty” on a nil GST return? How the GSTR-3B late fee cap works

Last updated 13 Oct 2026 · India

Short answer. Yes, a registered person has to file GSTR-3B even when there was no business at all, and a late return attracts a late fee. Since the tax period June 2021, the late fee per return is capped by Notification 19/2021-Central Tax: ₹250 (CGST) where the central tax payable in the return is nil, ₹1,000 for turnover up to ₹1.5 crore and ₹2,500 for ₹1.5–5 crore. An equal State/UT GST fee usually applies, so the portal typically shows double, for example ₹500 for a nil return. Many months of missed nil returns is how people end up paying thousands.

“Form GSTR-3B can be filed as nil return when there are no transactions as well as liability to be reported and paid in that return for that particular tax period.”

— GST portal, Form GSTR-3B user guide (checked 13 Oct 2026)

Why a fee on a return with no business?

Your GST registration is a promise to report every period. A nil return tells the department "nothing happened"; without it, the system cannot tell a quiet month from a hidden one. So the fee is for not reporting, not for tax. That is why buyers call it unfair (“The charge Nil Return feels like extortion”) and why it hurts most people who registered and then never used the number.

The caps per return (tax period June 2021 onwards)

The fee accrues per day until the cap is reached, and the portal works it out for you. Each missed month (or quarter) is a separate return with its own cap, which is how 12 missed nil months become several thousand rupees.

Common mistakes

  • "I never used my GST number, so nothing is due." Returns stay due while the registration is active. If you no longer need GST, look at cancelling the registration on the portal rather than letting returns pile up.
  • Relying on SMS reminders. One buyer wrote that he stopped filing nil returns when the reminder messages stopped. Put the dates in your own calendar.
  • Trying the Nil option with a pending fee. The portal does not allow Nil filing while there is an outstanding interest or late fee liability; pay it through the return.
  • Waiting for a waiver. Past amnesties were one-off and time-bound. Filing now stops the next month's fee.

What to do if you have missed months

  • Log in to gst.gov.in and list every period not filed
  • File the oldest pending GSTR-1 and GSTR-3B first (the portal generally expects earlier periods to be filed before later ones)
  • Pay the late fee shown in the return
  • Decide: keep the registration (and file every period) or apply to cancel it
  • Set calendar reminders for the 20th (monthly) or 22nd/24th (quarterly)

Frequently asked questions

What is the maximum late fee for a nil GSTR-3B?

For tax periods from June 2021, the CGST late fee is capped at ₹250 per return where the central tax payable is nil. With the matching State GST fee, the total is usually ₹500 per return.

Do I have to file GST returns if I had no business?

Yes. While your GST registration is active you must file returns for every period, as nil returns if there were no transactions.

Why did I pay thousands in late fees with zero sales?

Each missed period is a separate return with its own late fee, capped per return. Many missed months add up to thousands even though each return is capped.

Can I file a nil GSTR-3B if a late fee is pending?

No. The GST portal does not allow the Nil filing option while there is an outstanding interest or late fee liability.
